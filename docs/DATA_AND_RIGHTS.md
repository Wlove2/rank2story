# 数据使用与隐私

本项目是网文市场研究与故事候选生成工作流。默认离线演示使用合成数据；真实采集与模型推理是否涉及网络，取决于使用者自己配置的平台、浏览器与模型服务。

## 开源仓库包含什么

- Python 工作流、三个 Skill、默认配置、离线测试与合成示例。
- 精选的**历史公开榜单元数据**：书名、部分公开笔名、榜位、平台当时展示的阅读量或积分，以及来源链接。
- 经整理的**五张故事选题卡**，包括故事构思与评审字段。它们是示例创作成果，不是第三方小说正文，也不代表已发表作品。

这些数据用于解释项目实际输出，而非提供第三方平台的镜像数据库。榜单与社交数据具有时效性；使用者应以原平台和其条款为准。

## 默认不提供、也不应提交

- Cookie、浏览器登录态、OAuth 授权、账号信息、API Key、模型凭据或密码。
- 私有模型地址、内网拓扑、本机用户路径、工作日志或个人隐私。
- 第三方小说正文及完整简介、封面原图、笔记全文、视频字幕、收费内容或带有效签名的临时下载链接。
- 上游项目没有明确可再分发授权的第三方脚本和字体映射源码。

运行日志、原始平台响应与个人写作成果应保存在**仓库之外的私有工作目录**。请勿将真实运行目录上传至 GitHub Issues、PR 或公共网盘。

## 真实运行的网络和模型边界

- `run` 初始化候选状态时不主动调用模型；`execute` 可向操作者指定的 OpenAI 兼容服务发送冻结证据包中的内容。
- 实时采集可能访问第三方网站；操作者应自行确定是否有权访问、是否需要登录，以及可接受的请求频率。
- 离线示例不发送原始数据至平台或模型服务。
- 本项目不承诺公开平台永久可用，也不保证所有地区或网站可复现历史采集结果。
