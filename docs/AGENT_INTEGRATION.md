# Agent / Skills 接入和使用

## 一句话安装

将以下指令发送给 Agent：

> 请阅读 https://raw.githubusercontent.com/Wlove2/rank2story/main/docs/INSTALL_FOR_AGENTS.md ，按文档在我允许的工作区下载 Rank2Story、接入三个 Skills，并引导我安全配置模型的地址、名称和必要的 Key。先完成安装和离线自检；没有权限时报告缺口，不要自动抓取大量网页或调用付费模型。

**[给 Agent 阅读的完整安装指南](INSTALL_FOR_AGENTS.md)**

安装指南包含项目下载、三个 Skills 接入、模型配置与环境检查。具体技能目录和工具权限由相应 Agent 平台提供。

## 用户只需指定三个维度

| 维度 | 选项 | 作用 |
| --- | --- | --- |
| 篇幅 | 长篇 / 短篇 | 确定作品体量、故事节奏和评审重点 |
| 目标平台 | 番茄 / 七猫 | 明确作品面向的平台定位与内容环境 |
| 受众频道 | 男频 / 女频 | 明确目标读者与故事侧重点 |

按照三个维度组合描述选题需求。例如：“使用 Rank2Story，为**番茄 · 男频 · 长篇**生成一批小说选题。”流程将完成市场数据核验、A/B/C 构思、编辑、双重审核与候选交付。

## 为什么采集七个平台，却只有番茄与七猫两个目标选项？

Rank2Story 将市场研究与作品定位分开处理。**市场来源**覆盖网文排行榜、读者社区和视频平台，旨在从不同渠道交叉参考题材趋势与阅读偏好；**候选目标平台**用于指导故事设计与评审，当前正式支持番茄、七猫两个选项。

起点、晋江、纵横、小红书和 Bilibili 等来源提供市场研究依据，并不直接对应当前候选作品的目标平台。因此，“番茄男频长篇”限定的是候选作品方向，而不是“只采集番茄榜单”。

## 三个 Skills 的职责

| Skill | 路径 | 职责 |
| --- | --- | --- |
| `novel-market-scan` | `skills/novel-market-scan/SKILL.md` | 有授权的市场数据采集、校验、保存市场证据包 |
| `novel-candidate-portfolio` | `skills/novel-candidate-portfolio/SKILL.md` | 用合格证据包生成并审核候选 |
| `novel-analyzer` | `skills/novel-analyzer/SKILL.md` | 判断需不需要扫描、复用证据包或生成候选 |

安装时保留**整个仓库**，因为 Skills 要访问根目录配置和兄弟 Skill 的代码。具体工具授权及限制见 [安装文件](INSTALL_FOR_AGENTS.md)。

## 市场证据包能重复使用

“**市场证据包**”（程序文件名通常是 `evidence_packet.json`）可理解为一份**带采集日期、来源记录和校验结果的市场资料存档**，内容保存后保持固定，不是自动更新的实时榜单。

同一份满足**篇幅、来源覆盖和时效要求**的证据包可以用于**多次独立候选生成**。例如先生成一批番茄男频长篇候选，之后再说：

> 沿用上次的市场证据包，再生成一批番茄男频长篇候选；不要重新扫榜，重新构思并审核一批新的候选。

程序为每一批新建不同任务 ID，重新生成并校验结果，不覆盖上一批。每次新建任务都可指向同一个 `--packet` 文件路径。不是简单复读旧候选，也不保证跨批绝不重复；需要新趋势时必须刷新来源，不能把旧数据冒充当天采集结果。不同篇幅的证据要求也可能不同，不应无校验跨篇幅强行复用。若用户明确要求近期社交信号并提供天数，应新建扫描并设置 `--max-social-age-days N`，使社交来源按冻结的 UTC 日期窗口校验，而非自动把历史证据视作最新。

## 配置 Skills 使用的模型

不需要安装额外的“模型任务系统”。在项目根目录的个人配置 `.env`（或 Agent 的安全环境）中填写：

```dotenv
MODEL_BASE_URL=https://your-endpoint.example/v1
MODEL_ID=your-model-id
MODEL_API_KEY=
```

模型地址、名称、Key 必须用用户自己的真实配置替换示例。让 Agent 创建本地配置模板，**Key 由用户在本地编辑器或安全凭据管理中输入，不应在聊天中粘贴**。项目会在候选生成时自动读取配置。

当前候选生成代码需要可调用的 OpenAI 兼容 HTTP API；Agent 内置聊天模型不会未经适配自动变成该接口。详细说明见 [简易指南](QUICKSTART.md)。

## 不使用 Agent 的高级方式

同一套 Skills 工作流还可在 Python CLI 中运行；参阅 [手动模式](QUICKSTART.md)。真实采集可能要求合法网页访问、浏览器和外部适配器，单靠安装 Skills 不保证七平台实时抓取。
